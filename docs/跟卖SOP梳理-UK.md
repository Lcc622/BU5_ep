# BU5-跟卖 SOP 梳理

> 来源：kdocs.cn 文档，作者：TERESA，最后更新：2026-03-13

---

## 一、目标（Goal）

在新版本 SKU 入库后，快速完成跟卖上新，实现：

- 新老版本同时存在购物车
- 新版本价格高于老版本 $0.1，老版本优先出单
- 用真实销售测试退货率变化
- 降低人工制表错误
- 实现半自动化批量生成上传模板

---

## 二、整体流程结构

```
输入新版本 SKU
↓
匹配老版本 SKU
↓
抓取老版本 ASIN
↓
生成跟卖上新表
↓
人工复核
↓
上传 Amazon
```

---

## 三、详细操作步骤

### Step 1：输入触发

**目标**：确认需要跟卖的新版本 SKU

**后缀规范**：
- `-UK1+` 后缀统一变成 `-UK1`
- `-DE` 后缀统一变成 `-DE`

**操作**：
- 输入：新版本 SKU（支持批量）
- 精确到 SKU 级别（不是 style）

---

### Step 2：匹配老版本 SKU

**目标**：找到新版本对应的老版本 SKU

**逻辑**：
- 系统根据新版本 SKU
- 在 BI 入库更新表中匹配老版本 SKU

**输出**：
- 新版本 SKU
- 对应老版本 SKU

> 若 BI 无法稳定匹配，可使用人工维护的新老 SKU 对照表。

---

### Step 3：抓取老版本 ASIN

**目标**：获取老版本对应的 ASIN

**逻辑**：
- 根据老版本 SKU
- 调用 Amazon 后台 Only Thing Report 或内部接口
- 抓取老版本 ASIN

**输出**：
- 老版本 ASIN

---

### Step 4：生成跟卖上新表（字段规则最终版）

#### 一、必须修改字段清单

以下字段为**强制更新字段**：

| # | 字段名 | 规则 |
|---|--------|------|
| 1️⃣ | `item_sku` | 填写新版本 SKU；不可为空；必须唯一 |
| 2️⃣ | `product_id` | 填写老版本 ASIN；用于跟卖挂靠 |
| 3️⃣ | `product_id_type` | 批量填写：`ASIN`；所有行必须一致 |
| 4️⃣ | `model_style_number` | 填写新版本 SKU |
| 5️⃣ | `part_number` | 填写新版本 SKU；与 model_style_number 保持一致 |
| 6️⃣ | `standard_price` | 新版本价格 = 老版本价格 + 0.1；必须高于老版本；保留两位小数；不允许随意改动 |
| 7️⃣ | `list_price` | `list_price = (老版本价格 + 0.1) + 10`；保留两位小数；批量统一计算；不允许手动单独修改 |
| 8️⃣ | `quantity` | 批量填写：`2`；避免库存错误，后续由库存系统同步 |
| 9️⃣ | 所有 `image` 列 | **全部清空**；不允许保留任何图片链接；原因：跟卖不需要重新上传图片，避免触发图片审核 |

#### 二、其他字段不变（全部沿用老版本）

包括但不限于：
- 标题
- 五点
- 描述
- 类目
- 变体结构
- 品牌
- 尺码属性
- 颜色属性
- 材质属性

---

## 五、最终字段计算逻辑汇总（给开发）

```
new_price = old_price + 0.1
list_price = new_price + 10

quantity = 2
image = null
product_id_type = ASIN
```

---

## 六、人工复核清单（上传前）

上传前必须确认：

- [ ] SKU 是否正确
- [ ] ASIN 是否匹配
- [ ] price 是否 +0.1
- [ ] list_price 是否 +10
- [ ] quantity 是否为 2
- [ ] image 是否清空

确认无误后上传 Amazon。

---

## ⚠️ 现存问题（关键坑位）

### 问题

BI 上新排查界面只显示**已入库的部分 SKU**，但实际业务要求是：

> 只要一个 SKC（颜色）开始入库，该颜色下**所有 SKU（所有尺码）都必须安排跟卖上新**。

**风险**：
- 可能只入库 2 个 SKU，但该颜色共有 8 个 SKU
- 如果只按 BI 显示的 2 个做跟卖 → 同色断码、变体结构异常

### 解决方式（新增必要步骤）

**必须按照原有老版本有的全部 SKU，完成所有 SKU 的跟卖上新**，确保：
- 不漏尺码
- 不漏 SKU
- 不破坏变体结构
